Network Overview Dashboard

Resume Project 1 Project 2

Description

This project provides a heads up monthly view of the network utilization and events, with in depth
pages providing historical and more detailed data for different sectors and divisions of the enterprise
network.

The project rests upon two main factors, the first of which being an automatic monthly script. The script
parses automatic data from network monitoring tools and uses API calls to other monitoring tools to gather
in depth information on device load, connected clients, and much more on both large and small scales. The second
key piece to this project is the dashboard itself, built in PowerBI and outfitted with multiple formulas and
scripts to automatically pull information and prepare it for high level view, without any human input needed.

The project was geared at C-level administrators, providing a brief snapshot of monthly usage statistics
across campus, and providing useful trendlines and expring contracts for immediate consideration and deliberation.
The dashboard itself sees monthly use, and was adapted using PowerBI Report Builder to automatically make a
distributable version that is easily printable and reviewable at any time for upper management.

This project was developed over the course of several months, seeing the scope and requests gradually
evolve from a simple snapshot tool to an in depth, historical tracker for the entire organization and
resources. To this day, it continues to be referenced for easy trend data, important outage information,
and historical data that can easily be accessed without having to query multiple tools like in the past.

Skills Gained
